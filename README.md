# 新北市立三多國中｜九年級自然科段考複習與能力診斷系統

本系統收錄 **114 學年度第一學期第二次段考九年級自然科試題（全原圖）**，並對應 **115 學年度康軒版課本（第 2 章 力與運動、第 3 章 功與能、第 6 章 板塊運動與地球歷史）** 提供線上測驗、自動批改、**個人能力值六角圖**與**依答錯率排序之課本頁碼複習建議**。

## 系統特色
1. **學生資料登錄**：第一頁填寫班級、座號、姓名與電子信箱。
2. **原汁原味試卷**：題目 29 張插圖均直接擷取自段考原始試卷 PDF，無重繪誤差。
3. **個人能力值六角圖 & 複習處方**：交卷後即時計算總分（選擇 80 分 + 手寫 20 分），依據 6 大單元答錯率繪製六角圖，並標示對應 **115 課本頁碼** 的優先複習章節與逐題詳解。
4. **一鍵寄送成績單至學生信箱**：結合 Google Apps Script 自動將總分、六角圖圖片與個人複習建議寄送到學生一開始填寫的 Email，並可同步收集全班作答紀錄至 Google 試算表。

## 老師專用：1 分鐘啟用 Google 自動寄信與成績試算表

1. 開啟一個新的 [Google 試算表](https://sheets.new)（之後全班的作答成績會自動紀錄在這份表單中）。
2. 點選上方選單 **「擴充功能」→「Apps Script」**。
3. 將本專案中 [`gas/Code.gs`](gas/Code.gs) 的全部程式碼複製貼上，取代原本內容並按 `Ctrl + S` 儲存。
4. 點選上方 **「部署」→「新增部署作業」**：
   - 類型選擇：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 點選「部署」並完成 Google 帳號授權後，複製產生的 **網頁應用程式網址**（格式為 `https://script.google.com/macros/s/.../exec`）。
6. 將該網址貼到 `index.html` 第 527 行左右的 `GAS_WEB_APP_URL` 常數中並推送更新（或在網頁結果頁右上角點選「⚙️ 寄信服務設定」貼上測試）。
