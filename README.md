# 新北市立三多國中｜九年級自然科段考複習與重組段考系統

本系統收錄 **112、113、114 學年度第一學期第二次段考九年級自然科試題（全原圖）**，並對應 **115 學年度康軒版課本（第 2 章 力與運動、第 3 章 功與能、第 6 章 板塊運動與地球歷史）** 提供線上測驗、自動批改、**個人能力值六角圖**與**依答錯率排序之課本頁碼複習建議**。

## 系統特色
1. **學生資料登錄與年度選擇**：第一頁填寫班級、座號、姓名與電子信箱後，可自由選擇 **112、113、114 學年度原卷**、**🎲 【重組段考】**，或是挑戰 **😈 【魔王難度】（全卷單選 40 題高階挑戰試題）**。
2. **【重組段考】智慧防背答案組卷**：依 112～114 三年各章節出題比例分層隨機抽取單選 32 題（80 分）與手寫 4 題共 10 格（20 分），題組不拆散，且**每題選項順序自動洗牌**，避免學生背誦答案字母刷題。
3. **原汁原味試卷圖片**：題目插圖直接擷取自歷屆段考原始試卷，與紙本試卷 100% 一致。
4. **個人能力值六角圖 & 複習處方**：交卷後依據 6 大單元答錯率繪製六角圖，標示對應 **115 課本頁碼** 的優先複習章節與逐題詳解。
5. **一鍵寄送成績單至學生信箱**：結合 Google Apps Script 自動將總分、六角圖圖片與個人複習建議寄送到學生一開始填寫的 Email，並可同步收集全班作答紀錄至 Google 試算表。
